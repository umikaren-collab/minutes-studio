# 議事録工房

MP4・音声・PDFと会議情報から議事録を作成し、Wordで保存するアプリ。Wordの差し込み書式、印刷設定、個人API、共有試用に対応。

## 共有試用の有効化

管理者は `/admin` からこのサイトのオーナーと同じChatGPTアカウントでログインし、APIキー・モデル・共有試用の開始／停止を設定する。管理APIも各リクエストでログイン状態とオーナーメールアドレスを照合し、別アカウント・未ログイン・別サイトからの変更を拒否する。`ADMIN_OWNER_EMAIL` はSitesから確認したオーナーのメール、`API_KEY_ENCRYPTION_SECRET` は暗号用の32バイト乱数をbase64url形式にした値で、両方ともSitesの秘密設定に保管する。これらは公開画面から変更できない。APIキーはGoogleのモデル情報APIで利用可否を確認してからAES-GCMで暗号化してD1に保存する。保存済みキーの全文は画面・APIレスポンス・ログに返さない。従来の `GEMINI_API_KEY` 環境変数も既存設定の互換用として扱い、管理画面の登録が優先される。

モデル設定は `gemini-3.5-flash-lite`（初期値）、`gemini-3.8-flash`、`gemini-2.5-flash`。APIモデルの提供状況・無料枠・料金はGoogle AI Studioで確認する。キーが未登録の場合、共有試用は作動しない。サイトの閲覧範囲は別途Sitesのアクセス設定で指定する。

## 制限

共有試用は利用者全員で1日5回（`lib/limits.mjs` の `DAILY_LIMIT` で変更）。日本時間0時にリセット。サーバーD1の原子的カウンターで管理し、処理開始後のAPI失敗・入力トークン超過も1回と数える。自動再試行なし。資料は1ファイル200MB、合計500MBまで。4MBごとに分割し、サーバーからGoogle Files APIへ転送する。アプリのサーバーではファイル全体をメモリーに読み込まない。入力は1,000,000トークンまで、出力は32,768トークンまで。生成のたびにGoogleのモデル情報APIで選択モデルの入出力上限を取得し、小さいほうを使う（取得できない場合は出力8,192トークン）。生成の待ち時間は最大5分。アップロード開始から生成までを1回として数え、開始後の失敗も含む。無料APIのプロジェクト枠はこのカウンターとは別で、太平洋時間0時にリセットされる。

APIキーと資料を共有先に公開しない。会議情報・資料は生成時にGoogle Gemini APIへ送信する。アプリのDBには日付・使用回数、暗号化済みAPI設定、アップロードの一時的な進捗・接続情報を保存し、会議資料や議事内容は保存しない。アップロードの確認用トークンはハッシュのみ保存し、2時間で失効する。Google側の一時ファイルは生成完了・中止時に削除を試み、Google Files APIでも自動削除される。無料APIのデータ利用条件は有料枠と異なる。無料枠では送信内容がGoogleの製品改善に利用される場合があるため、社内会議・個人情報を含む資料を扱う場合はGoogle AI Studioでプロジェクトの課金を有効にする。

管理画面の「課金を有効にしたGoogle Cloudプロジェクトのもの」チェックで有料枠を申告する（Google側から自動判定はできない）。申告がない間、利用画面に「機密資料を送信しない」よう警告を表示する。新しいキーを入力するとチェックは外れ、改めて申告が必要になる。環境変数のキーを使う場合は `GEMINI_PAID_TIER=true` で同じ扱いになる。

公開試用版の画面にはAPIキーやモデルを変更する欄を設けない。API設定はログイン済みのオーナー専用管理画面に限定する。継続利用者が自分のAPIを使う場合は、別途専用アプリ・設定を用意する。

## 印刷設定

標準WordではA4・A3・JIS B5、縦横、余白、本文文字サイズ、行間を反映する。差し込み式Word書式は初期状態で既存設定を維持し、チェックを外すと全セクションの用紙・向き・余白だけを上書きする。ページ数、印刷部数、両面印刷はWordで確認・設定する。

## 検証

`npm test` でテスト、`npm run lint` でlint、`npm run format` で整形（Prettier）。

`npm run db:generate` でスキーマ変更のSQLを生成。Sitesのビルド・公開フローでWorkerとマイグレーションを反映する。
