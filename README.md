# 議事録工房

録音・動画・PDFから議事録を作り、Wordで保存するWebアプリです。

**ブラウザだけで動きます。** 資料はあなたのブラウザーから直接 Google の Gemini API に送られ、作者のサーバーなど、ほかの場所は経由しません。AIの利用には、**ご自分の Gemini APIキー（有料枠）** が必要です。

👉 **使ってみる：** https://umikaren-collab.github.io/minutes-studio/

## できること

- 録音（WAV・M4A・MP3・AAC・FLAC・OGG・AIFF・WebM）、動画（MP4）、PDF をまとめて取り込み（最大5件・1件200MB・合計500MB）
- 会議名・日時・出席者・議題を入れて、【議事内容】【決定事項】【今後の対応】【要確認事項】の形に整理
- まとめ方（標準・簡潔・詳細）と文体（である調・です・ます調）を選択
- 画面上で修正して、Word（.docx）でダウンロード
- 自社の書式（Word・PDF）を指定可能。Wordに `{会議名} {日時} {場所} {出席者} {議題} {議事内容}` を置けば、レイアウトを保ったまま差し込み
- 用紙サイズ・向き・余白・文字サイズ・行間を指定

## はじめに：APIキーを用意する

1. [Google AI Studio](https://aistudio.google.com/apikey) で APIキーを発行します。
2. そのキーのGoogle Cloudプロジェクトで**課金（請求先アカウント）を有効に**します。
3. アプリ右上の「APIキー設定」にキーを貼り付け、「有料枠のものです」にチェックして「確認して保存」。

> **なぜ有料枠だけ？** 無料枠のキーでは、送信した内容がGoogleの製品改善に使われる場合があります。会議資料を守るため、このアプリは有料枠のキーでの利用を前提にしています。利用料金はキーの持ち主に請求されます（1回あたりの費用は資料の長さとモデルによります。Google Cloudで予算アラートを設定しておくと安心です）。

## 使い方

1. 会議の基本情報を入力
2. 録音・動画・PDFを選ぶ（文字起こし済みのテキストを貼り付けるだけでも可）
3. 「Gemini APIに送信」にチェックして「議事録を作成する」
4. 内容を確認・修正し、「Wordでダウンロード」

## データとAPIキーの扱い

| 項目 | 扱い |
| --- | --- |
| 会議資料・入力内容 | ブラウザーから Google Gemini API へ直接送信。アプリ側には保存しません |
| Google側の一時ファイル | 作成後（失敗・中止時も）に削除。削除できなかった場合も48時間で自動削除 |
| 作成した議事録 | 画面を閉じると消えます。必要なものはWordで保存してください |
| APIキー | 「この端末に保存」を選んだ場合のみブラウザーに保存。選ばない場合はタブを閉じると消えます |

通信先は Content Security Policy で Google の Gemini API（と表示用のGoogle Fonts）だけに制限しています。共用のパソコンでは「この端末に保存」をチェックしないでください。

AIの出力には誤りが含まれることがあります。氏名・数値・決定事項は必ず原資料と照合してください。

## 自分の環境に置く（フォーク・自前ホスティング）

このリポジトリはビルドすると静的ファイル（HTML・JS・CSS）だけになるので、どこにでも置けます。

- **GitHub Pages：** このリポジトリをフォーク →「Settings」→「Pages」→「Source」を **GitHub Actions** に設定 → `main` に push すると自動で公開されます。
- **社内サーバーなど：** `npm ci && npm run build` で作られる `dist/` フォルダーを、HTTPSのWebサーバーに置くだけです。

## 開発

Node.js 20 以上。

```sh
npm install
npm run dev      # 開発サーバー（http://localhost:5173）
npm test         # テスト
npm run build    # dist/ に出力
```

| ファイル | 役割 |
| --- | --- |
| `src/main.js` | 画面と操作、Word出力 |
| `src/gemini.mjs` | Gemini API（ファイル転送・生成・一時ファイル削除） |
| `src/key-store.mjs` | APIキーの保存（localStorage / sessionStorage） |
| `src/file-import.mjs` | 取り込める形式・容量の判定 |
| `src/print-settings.mjs` | 用紙・余白などのWordページ設定 |
