# 議事録工房

録音・動画・PDFから議事録を作り、Wordで保存するWebアプリ。

招待制です。管理者が相手ごとに**招待コード**を発行し、コードを持っている人だけが使えます。AIは管理者のGemini APIキー（有料枠）を使うため、利用者がキーを用意する必要はありません。

## 使い方（利用者）

1. 受け取ったURLを開き、利用コードを入れて「確認」
2. 会議情報と資料を入れて「議事録を作成する」
3. 内容を確認・修正し、Wordでダウンロード

## 管理（オーナー）

`/admin` にオーナーのChatGPTアカウントでログインします。

- **APIキー**：有料枠のキーを登録し、「有料枠」にチェック。無料枠のキーは使えません。
- **全体の上限**：全員合計の1日の回数（1〜200回）。
- **招待コード**：相手ごとに発行・回数変更・停止・削除。コードは発行時に一度だけ表示されます。

回数は日本時間0時にリセット。失敗した場合も1回と数えます。

## データの扱い

資料は作成時にGoogle Gemini API（有料枠）へ送ります。このアプリには資料・議事録を保存しません。

## 開発

`npm test`（テスト）、`npm run lint`、`npm run format`。設置手順は [docs/SETUP.md](docs/SETUP.md)。
